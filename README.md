# 🎓 Skillyug

### Empowering Students to Learn, Practice & Succeed

**Skillyug** is a student-focused educational platform designed to help students prepare for the **National Means-cum-Merit Scholarship (NMMS) Examination** through structured learning, practice, assessments, and performance tracking.

> 🚀 Built with the vision of making NMMS preparation more accessible, engaging, and organized for students.

---

## 🌟 About Skillyug

Preparing for competitive scholarship examinations can be challenging for students, especially when learning resources, practice questions, and performance analysis are scattered across different platforms.

**Skillyug brings these learning experiences together in one platform.**

Students can use Skillyug to:

- 📚 Learn through structured educational content
- 📝 Practice examination-style questions
- 🧠 Improve problem-solving skills
- 📊 Track their learning and performance
- 🎯 Identify areas that need improvement
- 🚀 Prepare more effectively for the NMMS examination

---

## 🎯 Our Mission

Our mission is to help students build:
